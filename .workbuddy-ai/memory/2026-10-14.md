## 修复：user 账号资料卡显示为历史昵称 "xbzz"

**现象**：用 `user/user123` 登录，资料卡主标题显示 "xbzz" 而不是 "user"。

**根因**：`user` 行的 `nickname` 是早前用旧编辑表单改过的历史值 "xbzz"，`real_name` 为空，展示回退链 `realName || nickname || username` 落到 nickname。

**修复（两层）**
1. **数据自愈**：`schema.sql` 末尾加 `UPDATE \`user\` SET \`nickname\` = \`username\` WHERE \`nickname\` IS NULL OR \`nickname\` <> \`username\`;` —— 每次启动自动归一，幂等。已重启后端验证启动脚本可正常执行。
2. **展示层去依赖**：前端回退链统一改为 `realName || username`，不再引用 nickname（`Profile.vue` displayName、`Layout.vue` 管理员名与头像首字、`Users.vue` 头像首字）。nickname 退化为纯只读镜像字段。

**附带处理**：老库 `admin` 行 nickname 原为 "管理员"，归一后会变 "admin"，故一次性把 `admin.real_name` 补为 '管理员'（与 DataSeeder 新建库行为对齐），管理端顶栏仍显示「管理员」。

**验证**：headless 截图确认 `user` 卡片主标题为 "user"、管理端顶栏为「管理员」、用户列表头像首字正确（admin→管 / user→u / xbzz→x）；接口返回 `nickname: "user"`。

## 用户端改造成固定手机框 + 内部滚动

**问题**：桌面浏览器打开用户端时，页面被内容撑长，上下出现背景色差；`van-dropdown-item`（筛选下拉）宽度按视口算，溢出手机框。

**方案（关键技巧：用 transform 造包含块）**
- `body { overflow: hidden }`，`#app { position: relative; height: 100%; overflow: hidden }`
- `App.vue` 改成 `<div class="app-scroll">router-view</div> + <van-tabbar fixed>`，滚动交给 `.app-scroll`
- 桌面媒体查询：`#app { max-width: 430px; margin: 0 auto; transform: translateZ(0) }`
- **`transform` 让 `#app` 成为内部 `position: fixed` 元素的包含块** → nav-bar / tabbar / 下拉筛选 / 底部弹层 / 遮罩全部自动收进手机框，**无需逐个组件覆写宽度**（旧代码里针对 `.van-nav-bar--fixed`、`.van-tabbar--fixed`、`.van-popup--bottom` 的手工 `left:50%/margin-left` 覆写已删除）
- 页面根 `min-height: 100vh` → `100%`（Home/Detail/Login/Profile 四处）

**实测**：`#app` 430px@left505、`.van-dropdown-item` 430px@left505（不再溢出）、`.app-scroll` scrollHeight 1429 > 900（框内滚动）、`body.scrollHeight` = innerHeight（页面不滚动）。

**前端**

## BI 看板改为「房源 + 营业额」视角

**需求**：不关心成交量（笔数），只关心①房子总套数 ②待租套数 ③当月成交金额；中间 KPI 卡改成当月营业额/当日营业额；月度成交趋势图改成营业额对比（能看出本月 vs 上月）；房源占比保留。

**营业额口径（关键）**：Demo 无支付/订单模块，营业额 = **该时段内未取消预约记录所对应房源的月租金合计**（`SUM(apartment.rent)` JOIN）。副作用：管理员改租金会影响历史营业额，属 Demo 简化，已写入 PRD。若房源被删，其 booking 会级联删除，不会产生悬空记录。

**后端**
- `BookingMapper`：删掉 `selectMonthlyTrend` / `selectDailyTrend`（笔数），新增三条营业额 SQL —— `selectMonthlyRevenue`（近6月）、`selectDailyRevenue`（近7天）、`selectRevenueBetween(start,end)`；SUM 结果统一 `CAST(... AS SIGNED)`，避免 BigDecimal 序列化成 `5400.00`
- `StatsService.bi()` 返回改为：`totalApartments` / `vacantCount` / `monthRevenue` / `dayRevenue` / `lastMonthRevenue` / `monthGrowth` / `revenueTrend` / `dailyRevenue` / `statusPie`
- `growthRate(current, last)`：**上月为 0 时返回 null**（无法计算环比），前端据此显示「上月无营业额」

**前端（rental-bi/Dashboard.vue）**
- KPI：总房源数（brand）/ **当月营业额**（amber，主数值 `¥5,400`，副行「当日 ¥x · 环比上月 ↓26%」）/ 待租房源数（teal）
- 副行用 `v-html` + 内部生成标签实现环比着色（`.up` teal / `.down` danger / `.flat` faint）；因 v-html 内容不在 scoped 作用域，样式需 `:deep()`
- 大图：「月度营业额对比」柱状图，近 6 个月，**当月柱用 amber 高亮、其余 rgba(42,79,215,.26) 浅蓝**，柱顶标 `¥金额`，便于一眼对比本月与上月
