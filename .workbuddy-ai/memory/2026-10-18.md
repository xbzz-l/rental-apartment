# 2026-10-18 工作日志

## Vite 支持 cpolar 内网穿透访问（11:04）

**需求**：用 cpolar 把三端 dev server 暴露到公网，但访问公网域名时报「Blocked request / This host is not allowed」，需在白名单里加三个公网地址。

**原因**：Vite 5.4.12+ 加了 Host 校验（CVE-2025-30208 等修复），未登记的 Host 一律 403。

**改动**（三端 `vite.config.js` 各加两段，其余不动）
```js
server: {
  port: 517x,
  host: true,                 // 默认只监听 localhost，穿透需放开
  allowedHosts: [
    '30f9c13c.r30.cpolar.top', // 5173 用户端
    '1d2bae60.r30.cpolar.top', // 5174 管理端
    '367b79f2.r30.cpolar.top'  // 5175 BI
  ],
  ...
}
```
- 三个域名在每个 config 里都登记了（冗余但无害，换端口也不用改）
- 实际安装 Vite 版本 5.4.21，支持 `allowedHosts`

**验证**（临时起 5173，curl 带不同 Host 头）
- `30f9c13c.r30.cpolar.top` / `1d2bae60...` / `367b79f2...` → 全部 200
- `evil.example.com` → 403（白名单确实生效，不是空配置）
- `localhost` → 200（本地开发不受影响）
- 验证后已关闭 dev server，端口全部释放

**注意**
- 页面能打开 ≠ 有数据：`/api` 与 `/images` 仍代理到 `localhost:8080`，演示前必须先跑 MySQL + 后端（`start-all.bat`）
- cpolar 免费版域名每次重启会变，变了要同步改 `allowedHosts`
- https 隧道下 Vite HMR 的 websocket 可能连不上（不影响页面浏览，只是热更新失效）；本地开发仍用 localhost 即可

## 确认「前端代理后端」已天然生效，无需改配置（11:40）

**用户想法**：只穿透前端，不映射后端，靠前端配置代理后端，「顺便保护后端」。

**结论：这套机制项目里本来就是这么做的，不用改任何配置**
- 三端 `src/api/request.js` 均为 `baseURL: '/api'`；`src` 里 grep 不到任何 `:8080` 硬编码
- 代理写在 `vite.config.js` 的 `server.proxy`：`/api` 与 `/images` → `http://localhost:8080`（`changeOrigin: true`）
- **Vite 代理是 Node 进程侧的转发**，浏览器只跟隧道域名通信，8080 从未暴露给外网

**端到端实测**（起 MySQL + 后端 + 三端 dev server，curl 带公网 Host 头模拟外网）
| 公网域名 | 端口 | 页面 | /api/apartments |
| --- | --- | --- | --- |
| 30f9c13c.r30.cpolar.top | 5173 | 200 | 200，total=18 |
| 1d2bae60.r30.cpolar.top | 5174 | 200 | 200，total=18 |
| 367b79f2.r30.cpolar.top | 5175 | 200 | 200，total=18 |
另测：`/images/apartments/apt9.jpg` 200（197KB image/jpeg）、`POST /api/auth/login` 经代理返回 token（144 字符）

**遗留安全点 → 已修复，见下一节**

## 后端锁定为仅本机监听（12:30）

**需求**：后端不该监听整个网段，只应监听本机，由本机 Vite 代理转发。

**改动**（`rental-server/src/main/resources/application.yml`）
```yaml
server:
  port: 8080
  address: 127.0.0.1   # 只监听回环，局域网无法直连
```

**验证**（重启后端后）
| 检查项 | 结果 |
| --- | --- |
| `netstat` 绑定地址 | `127.0.0.1:8080`（原为 `0.0.0.0:8080` + `[::]:8080`） |
| `http://127.0.0.1:8080/api/apartments` | 200 |
| `http://localhost:8080/api/apartments` | 200（doc.html 照常可用） |
| `http://192.168.1.98:8080/...`（本机 WLAN IP） | HTTP 000，连接被拒 ✔ |
| 三端经 cpolar 域名代理 | 5173/5174/5175 全部 200，total=18 |
| 管理端 admin 登录（经代理） | token 145 字符 |
| BI 统计（经代理） | 总房源 18、近 6 月趋势 6 个点 |

**注意**：Vite 代理 target 仍写 `http://localhost:8080`，Node 20+ 的 autoSelectFamily 会自动在 ::1 / 127.0.0.1 间回落，实测正常；若哪天代理报 ECONNREFUSED，把三端 `proxy.target` 改成 `http://127.0.0.1:8080` 即可。
